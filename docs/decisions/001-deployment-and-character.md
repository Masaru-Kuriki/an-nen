# 判断001: 配布範囲とアンミカキャラ採用

決定日: 2026-06-03
ステータス: 確定

## 結論

- **アンミカ風AI生成似顔絵キャラを採用する**
- **そのため配布範囲を「身内約10人のみ」に絞り、公開しない運用にする**
- ホスティングは GitHub Pages or Cloudflare Pages、認証なし、URLを身内にだけ共有

## 背景

アンミカさんの名言「白って200色あんねん」をテーマにしたネタゲー。
当初はApp Store公開 → Webアプリ公開（拡散重視）→ 身内10人限定（クローズド運用）と方針が変遷。

## 判断の経緯

### 検討した選択肢

1. **アンミカ似顔絵を使わない**（オリジナル別人キャラ、テキスト演出のみ等）
   - 法的リスクゼロ、拡散OK
   - 世界観の核が薄まる、ネタとして弱くなる

2. **アンミカ似顔絵を使う + クローズド配布**（採用）
   - 世界観の核を維持できる
   - 法的リスクは身内限定により実質ゼロ近くに抑えられる
   - 拡散・SNS共有・パブリック公開は諦める

3. **アンミカ似顔絵を使う + パブリック公開**
   - 拡散性最大
   - 肖像権・パブリシティ権侵害のリスクが顕在化（炎上・削除要請・賠償リスク）

### 採用理由

くりさんは「ネタの面白さの核はアンミカ感」と判断。
法的リスク（肖像権・パブリシティ権はAI生成・似顔絵でも適用される、判例あり）を認識した上で、
**配布範囲を縮小することでリスクを実質化させない** ことを選択。

## 法的リスクに関する重要な前提（次のチャットへの申し送り）

以下はくりさんが認識済みの事項。次のチャットで再度リスク警告を出す必要はない。

- AI生成画像でも、実在人物の特定可能なものは肖像権・パブリシティ権の対象
- 似顔絵・イラスト・3DCG・写真、いずれも媒体は問わない
- ピンク・レディーDe事件（最高裁2012）等の判例で確立
- アンミカさんは現役タレント（オスカープロモーション所属）
- 文化庁2023年見解でもAI生成画像のリスクは指摘済み

くりさんはこれらを承知のうえで「身内10人で楽しむ」ことを選択した。

## 運用上の制約（次のチャットが守るべきこと）

1. **パブリック公開しない**（App Store / 一般Webへの公開は禁止）
2. **SNS拡散しない**（くりさんがネタとして自分のSNSに投稿するのもリスクあり）
3. **URL検索除け**（`robots.txt` で `Disallow: /` 設定必須）
4. **配布人数は10人前後を超えない**
5. **画像生成プロンプトに「アンミカ」を直接入れない**（ログ残ると面倒）

## キャッチコピーの建前と実体

- 建前: 「白って200色あんねん」
- 実体: 色マスタは約100色（実在の白系色名のみで揃う数）
- コレクション画面では数を明示しない（矛盾を見せない）
